# 🛒 Amazon Clone — HTML & CSS

Welcome to my **Amazon Clone** project! 👋

This is a **front-end** recreation of the Amazon shopping homepage, built using **HTML5 and CSS3**. The project helped me practice webpage structure, CSS styling, Flexbox, CSS Grid, hover effects, and layout design.

🔗 **GitHub Repository:** [Amazon Clone — Only HTML and CSS](https://github.com/Rahul-Chaurasiya-Code/Amazon-Clone-Only-HTML-and-CSS)

---

## ✨ Features

- 🧭 **Navigation Bar** — Logo, delivery location, search bar, account section, returns, and shopping cart.
- 🔍 **Search Bar UI** — Search input with a category selector and search icon.
- 📂 **Navigation Panel** — Menu icon, navigation links, and electronics deals section.
- 🖼️ **Hero Banner** — Promotional banner inspired by Amazon's homepage.
- 🛍️ **Product Categories** — Eight shopping categories arranged in a four-column grid.
- 🎨 **Amazon-Inspired Design** — Dark navigation bars, contrasting colors, borders, and spacing.
- 🖱️ **Hover Effects** — Interactive visual effects on selected navigation elements.
- ⭐ **Font Awesome Icons** — Icons for location, search, cart, menu, language, and currency.
- 🦶 **Footer Section** — Informational links, language and currency options, country selection, and legal links.

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### 1️⃣ Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/Rahul-Chaurasiya-Code/Amazon-Clone-Only-HTML-and-CSS.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd Amazon-Clone-Only-HTML-and-CSS
```

### 3️⃣ Open the Project

Open `index.html` in your preferred web browser.

💡 **Recommended:** Use [Visual Studio Code](https://code.visualstudio.com/) with the Live Server extension for a convenient development experience.

## ⚠️ Current Limitations

- This is a **front-end practice project** built with HTML and CSS.
- The search bar is currently a visual interface and does not perform product searches.
- The cart and account sections do not provide complete functionality.
- Some navigation and footer items are displayed for design purposes only.
- Responsive styling for smaller screens has not yet been implemented.
- There is no backend, database, authentication, or payment system.
